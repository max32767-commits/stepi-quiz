랜덤 게임 ⚡ 반응속도 대결 · 진행자

진행 방법

  1. 방 만들기 → QR로 참가자 입장 (폰이 서버 시계와 자동으로 맞춰집니다).
  2. 라운드 시작 → 3~8초 뒤 큰 화면과 모든 폰이 동시에 바뀝니다.
  3. 초록 GO면 빨리 누르기 → 반응시간 순위로 10·9·8…점. 빨강 STOP(페이크)이면 누르면 −5점, 참으면 +5점. 신호 전에 누르면 부정출발 −3점.
  4. 라운드마다 반응시간 순위 공개, 마지막에 총점 순위와 특별상(최고 반응속도·최다 낚임).
