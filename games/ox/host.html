문제 입력

한 줄에 한 문제, 문제|정답 형식. 정답이 여럿이면 /로 구분 (예: 세계에서 가장 긴 강은?|나일강/나일). O/X 문제는 |O, |X. 띄어쓰기·대소문자는 무시하고 채점합니다.

진행 방법

  1. 문제를 넣고 방 만들기 → 4자리 코드와 QR이 나옵니다.
  2. 참가자는 휴대폰으로 QR을 찍거나 코드를 입력해 이름을 넣고 들어옵니다.
  3. 문제 내기 → 제한시간 안에 참가자가 폰으로 답을 적어 제출합니다. 틀리면 다시 시도할 수 있어요.
  4. 맞히면 50점 + 속도 보너스(최대 50점) + 순위 보너스(1등 30·2등 20·3등 10). 시간이 끝나면 자동으로 정답과 순위가 공개됩니다.
  5. 문제를 다 내면 총점이 가장 높은 사람이 우승!
