문제 입력

한 줄에 한 문제. 끝에 |O, |X 또는 |정답 글자를 적으세요. 글자 정답이 여럿이면 /로 구분 (예: STEPI 소재지는?|세종/세종시). 띄어쓰기·대소문자는 무시하고 채점합니다.

진행 방법

  1. 문제를 넣고 방 만들기를 누르면 4자리 코드와 QR이 나옵니다.
  2. 참가자는 휴대폰으로 QR을 찍거나 코드를 입력해 이름을 넣고 들어옵니다.
  3. 문제 내기 → 참가자가 폰에서 O/X를 고르거나 글자로 답을 적습니다. 집계가 실시간으로 올라옵니다.
  4. 정답 공개 → 틀리거나 안 낸 사람은 탈락. 마지막까지 남은 사람이 우승!
