진행 방법

  1. 방 만들기 → 4자리 코드와 QR이 나옵니다.
  2. 참가자는 휴대폰으로 들어와 1~45 중 6개를 고릅니다 (자동 선택도 가능).
  3. 번호 마감 후 추첨 버튼을 누를 때마다 번호가 하나씩 나옵니다. 참가자 폰에서도 맞힌 번호가 실시간으로 켜져요.
  4. 6개를 다 뽑고 결과 확정 → 많이 맞힌 순으로 1·2·3등 (같으면 먼저 제출한 사람).
