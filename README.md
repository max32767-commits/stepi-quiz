# 확대 사진 퀴즈 (stepi-quiz)

사진을 넣으면 작은 조각부터 보여주고, 진행자가 "더 보기"를 누를 때마다 조금씩 넓혀 가며 맞히는 게임입니다. 워크숍·회식 등에서 진행자 한 명이 화면을 띄우고 여럿이 소리 내어 맞히는 용도로 만들었습니다.

- 실행: https://max32767-commits.github.io/stepi-quiz/
- 사진은 브라우저 안에서만 처리되며 서버로 올라가지 않습니다.

## 사용법
1. 사진을 여러 장 넣고 각 사진의 정답을 적습니다.
2. 단계 수, 시작 확대 배율, 드러나는 속도를 정합니다.
3. 게임 시작 → 더 보기 / 맞혔어요 / 정답 공개 버튼으로 진행합니다.

## 구조
- `index.html` 한 파일에 HTML·CSS·JS가 모두 들어 있습니다. 빌드 과정 없음.
